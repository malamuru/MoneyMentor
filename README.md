## ✨ Overview

MoneyMentor is a **full-stack personal finance tracking application** that helps users monitor their income, expenses, and overall financial health.

The application provides **real-time updates**, intuitive dashboards, and structured financial insights to support better decision-making.

---

## 🚀 Key Features

- 💵 Add and track income and expenses  
- 📊 Real-time financial updates using Firebase  
- 📈 Visual insights for spending patterns  
- 🧾 Organized transaction history  
- ⚡ Fast and responsive UI  
- 🌐 Deployed web application

## ⚙️ How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/malamuru/money-mentor.git
cd money-mentor
```
### 2. Install dependencies
```bash
npm install
```
### 3. Run the application
```bash
npm start
```
